# Portfólio Dev Full Stack — William Zambom

## Sobre o Projeto

Este projeto é o meu website de portfólio profissional, desenvolvido com o objetivo de apresentar meus trabalhos, habilidades técnicas, experiências e projetos desenvolvidos ao longo da graduação e da minha evolução como desenvolvedor.

A proposta é criar uma vitrine profissional moderna, limpa e estratégica, funcionando como ponto de entrada para recrutadores, clientes e oportunidades de estágio ou freelance.

O projeto está em constante evolução, acompanhando meu crescimento técnico e profissional.

---

## Objetivos

- Apresentar projetos desenvolvidos
- Mostrar tecnologias aprendidas na universidade e em projetos práticos
- Destacar competências técnicas e profissionais
- Facilitar contato profissional
- Apoiar processos seletivos
- Atrair clientes para serviços de desenvolvimento web
